Synthetic AV Dataset Generator
==============================

Procedural, deterministic, seed-based generation of synthetic autonomous-
vehicle perception datasets: road networks, lane topology, buildings,
traffic, sensor simulation, and ground-truth annotations, exported as
COCO datasets.

Specified in :doc:`architecture`; built phase-by-phase per
``MASTER_PROMPT_PROCEDURAL_AV_DATASET_GENERATOR.md`` (Phases 0-7 complete
-- see :doc:`release_notes`).

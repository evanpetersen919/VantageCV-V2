## 1.2 Core Principles

### Principle 1: Deterministic Generation from Seed
Every scenario is **fully reproducible** from a 64-bit integer seed.

```
seed: int64 → [RNG state] → Road Network → Lanes → Buildings → Meshes → Scene
```

Any change to generation code invalidates old seeds (tracked via git hash + version tag).

### Principle 2: Procedural > Manual
No manual object placement, material tweaking, or parameter tuning in UE5.

All configuration via:
- YAML scenario templates (declarative)
- Python algorithms (generative)
- Code-driven UE5 Blueprint factories

### Principle 3: Mathematical Rigor
Every algorithm backed by:
- Formal problem definition
- Mathematical formulation (with LaTeX)
- Numerical stability analysis
- Failure mode handling

### Principle 4: Scalability from Day 1
Architecture supports:
- Single GPU generation (development)
- Multi-GPU distributed generation (Ray)
- Cloud deployment (AWS, GCP)
- Horizontal scaling (add nodes linearly)

## 1.3 Scenario Taxonomy

All scenarios fall into one of these categories, each with formal definitions:

### Category 1: Urban Dense (High Complexity)
- **Definition**: Intersecting orthogonal/non-orthogonal streets with building facades
- **Formalization**: 
  - Intersection density > 0.01 intersections/m²
  - Building coverage ratio > 0.5
  - Mean degree of nodes ≥ 3.5
- **Example Metrics**: 4-9 intersections, 20-40m building heights, 6-14 lanes

### Category 2: Urban Sparse (Medium Complexity)
- **Definition**: Wider streets, lower building density, predominantly residential
- **Formalization**:
  - Intersection density 0.001-0.01 intersections/m²
  - Building coverage ratio 0.2-0.5
  - Mean block size 200-400m
- **Example Metrics**: 2-4 intersections, 15-30m heights, 2-6 lanes

### Category 3: Highway (Low Complexity, High Speed)
- **Definition**: Multiple parallel lanes, minimal cross-traffic
- **Formalization**:
  - Only parallel edges (no intersections)
  - Lane count ≥ 3 per direction
  - Minimum length ≥ 2km
  - Speed limit ≥ 80 km/h
- **Example Metrics**: 3-6 lanes total, 30m+ width, no intersections

### Category 4: Mixed Urban-Highway
- **Definition**: Blend of urban and highway features
- **Formalization**: Weighted combination of above categories

### Category 5: Parking Lots
- **Definition**: Regular grid of parking spaces
- **Formalization**: Regular lattice structure, no through-traffic

### Category 6: Roundabouts
- **Definition**: Circular topology with radial exits
- **Formalization**: Single central node, degree-n fan structure

## 2.1 Backend Engine

### Unreal Engine 5.4 LTS (NOT 5.3 or earlier, NOT experimental)
**Why 5.4 LTS?**
- Stable (LTS = Long-Term Support)
- Full C++20 support
- Mature Pixel Streaming (critical for remote rendering)
- Better Python API than 5.3
- Performance improvements (Nanite, Lumen mature)

**Installation Path:**
```bash
# Via Epic Games Launcher
# Download: UE 5.4.x (Latest patch)
# Install to: /opt/unreal/UE_5.4 (Linux) or C:\Program Files\Epic Games\UE_5.4 (Windows)

# Verify:
/opt/unreal/UE_5.4/Engine/Build/BatchFiles/RunUAT.sh --version
# Output: UE5.4.x
```

```ini
# DefaultEngine.ini (code-driven, not manual)
```

### 3.2.1 Implement Road Network Generator

**Mathematical Foundation: Planar Straight-Line Graphs (PSLG)**

Road networks are modeled as Planar Straight-Line Graphs where:
- Vertices V = {intersection nodes}
- Edges E = {road segments}
- Properties:
  - Connectivity: Each road connects exactly 2 nodes
  - Planarity: No crossing edges (roads don't cross except at intersections)
  - Embedding: 2D coordinates for each vertex

**Algorithm: Perturbed Grid Generation**

```
Input:
  - bounds: (x_min, y_min, x_max, y_max)
  - scenario_type: ScenarioType (enum)
  - seed: int64
  - config: ScenarioTypeConfig

Output:
  - nodes: Dict[int, RoadNode]
  - edges: Dict[int, RoadEdge]

Process:
  1. Initialize RNG with seed
  2. Compute grid spacing from config.avg_block_size
  3. Generate regular grid points
  4. Perturb each point by Gaussian noise
  5. Connect grid into minimum spanning tree
  6. Add secondary connections (randomized)
  7. Validate planarity and connectivity
  8. Assign road attributes (type, lanes, speed limit)
  9. Return graph
```

**Mathematical Formulation:**

Grid spacing:
```
spacing = U(min_block_size, max_block_size)  // Uniform random
```

Perturbation (Gaussian with controlled variance):
```
p'_i = p_i + N(0, σ²)  for each point p_i
where σ = 0.15 * spacing  // 15% of spacing
```

Connectivity (Delaunay triangulation, then filter):
```
For each triangle in Delaunay(perturbed_points):
  For each edge in triangle:
    Add edge if both endpoints within max_road_length
```

**Code Implementation:**

```python
# src/procedural/road_network.py

from typing import Dict, Tuple, Set
import numpy as np
from dataclasses import dataclass, field
from enum import Enum
from abc import ABC, abstractmethod

# Constants (immutable, globally defined)
MAX_ROAD_LENGTH_METERS = 500.0
MIN_INTERSECTION_DISTANCE_METERS = 10.0
GRID_PERTURBATION_RATIO = 0.15

class RoadType(str, Enum):
    """Road hierarchy"""
    HIGHWAY = "highway"        # 3-6 lanes, speed ≥ 80 km/h
    MAJOR = "major_arterial"   # 2-4 lanes, speed 40-60 km/h
    MINOR = "minor_street"     # 2 lanes, speed 30-40 km/h
    RESIDENTIAL = "residential"  # 2 lanes, speed ≤ 30 km/h
    ALLEY = "alley"           # 1-2 lanes, speed ≤ 20 km/h

class IntersectionType(str, Enum):
    """Intersection topology"""
    ISOLATED = "isolated"      # Not in road network
    T_JUNCTION = "t_junction"  # Degree 3
    FOUR_WAY = "four_way"      # Degree 4
    ROUNDABOUT = "roundabout"  # Special handling
    MERGE = "merge"            # Degree 2 but special

@dataclass
class RoadNode:
    """Vertex in road network graph"""
    node_id: int
    position: np.ndarray        # [x, y] center position
    node_type: IntersectionType
    elevation: float = 0.0      # For 3D road design
    
    # Adjacency lists
    incoming_edges: Set[int] = field(default_factory=set)
    outgoing_edges: Set[int] = field(default_factory=set)
    
    # Traffic control
    traffic_light: bool = False
    stop_sign: bool = False
    
    def __hash__(self):
        return hash(self.node_id)

@dataclass
class RoadEdge:
    """Edge in road network (single-directional segment)"""
    edge_id: int
    start_node_id: int
    end_node_id: int
    road_type: RoadType
    
    # Geometry
    centerline: np.ndarray      # [N, 2] polyline points
    length: float               # Euclidean length
    
    # Road attributes
    num_lanes: int              # Including both directions
    speed_limit_kmh: int        # Legal speed limit
    width_meters: float         # Total road width
    
    # Connectivity
    allows_turning_left: bool = True
    allows_turning_right: bool = True
    
    # Reverse edge (if bidirectional)
    reverse_edge_id: int = None
    
    def __hash__(self):
        return hash(self.edge_id)

class RoadNetworkGenerator:
    """Generate procedural road networks using PSLG theory"""
    
    def __init__(self, seed: int, config: 'ScenarioTypeConfig'):
        """
        Args:
            seed: 64-bit integer for reproducibility
            config: ScenarioTypeConfig defining network properties
        """
        self.seed = seed
        self.config = config
        self.rng = np.random.RandomState(seed)  # Seeded RNG
        
        # Stateful
        self._node_counter = 0
        self._edge_counter = 0
        self._nodes: Dict[int, RoadNode] = {}
        self._edges: Dict[int, RoadEdge] = {}
    
    def generate(self, bounds: Tuple[float, float, float, float]) \
            -> Tuple[Dict[int, RoadNode], Dict[int, RoadEdge]]:
        """
        Generate complete road network.
        
        Args:
            bounds: (x_min, y_min, x_max, y_max) in meters
        
        Returns:
            (nodes, edges) - fully connected road graph
        
        Raises:
            ValueError: If network fails validation
        """
        
        # Step 1: Generate grid points
        grid_points = self._generate_grid_points(bounds)
        
        # Step 2: Perturb for organic appearance
        perturbed_points = self._perturb_grid(grid_points)
        
        # Step 3: Create nodes and compute connectivity
        self._create_nodes_from_points(perturbed_points)
        
        # Step 4: Connect into edges (Delaunay + filtering)
        self._connect_nodes(bounds)
        
        # Step 5: Assign road attributes
        self._assign_road_attributes()
        
        # Step 6: Validate network
        self._validate_network()
        
        return self._nodes, self._edges
    
    def _generate_grid_points(self, bounds: Tuple[float, float, float, float]) \
            -> np.ndarray:
        """
        Generate regular grid of points.
        
        Mathematical formula:
          x_i = x_min + i * spacing, for i ∈ {0, ..., num_x}
          y_j = y_min + j * spacing, for j ∈ {0, ..., num_y}
        
        where spacing ∈ U(min_block, max_block)
        
        Args:
            bounds: (x_min, y_min, x_max, y_max)
        
        Returns:
            grid_points: [N, 2] array of (x, y) positions
        """
        x_min, y_min, x_max, y_max = bounds
        
        # Sample spacing from uniform distribution
        spacing = self.rng.uniform(
            self.config.avg_block_size[0],
            self.config.avg_block_size[1]
        )
        
        # Generate grid coordinates
        x_coords = np.arange(x_min, x_max + spacing, spacing)
        y_coords = np.arange(y_min, y_max + spacing, spacing)
        
        # Create Cartesian product (all (x,y) pairs)
        xx, yy = np.meshgrid(x_coords, y_coords)
        grid_points = np.column_stack((xx.ravel(), yy.ravel()))
        
        return grid_points
    
    def _perturb_grid(self, grid_points: np.ndarray) -> np.ndarray:
        """
        Add Gaussian perturbation to grid points.
        
        Mathematical formula:
          p'_i = p_i + N(0, σ²I)
        
        where σ = GRID_PERTURBATION_RATIO * spacing
              I = 2D identity matrix
        
        Purpose: Remove artificial regularity, create organic look
        
        Args:
            grid_points: [N, 2] grid points
        
        Returns:
            perturbed_points: [N, 2] perturbed points
        """
        # Compute spacing for this grid
        if len(grid_points) < 2:
            return grid_points
        
        dists = np.linalg.norm(np.diff(grid_points, axis=0), axis=1)
        avg_spacing = np.median(dists)
        
        # Perturbation standard deviation
        sigma = GRID_PERTURBATION_RATIO * avg_spacing
        
        # Apply Gaussian noise
        perturbation = self.rng.normal(0, sigma, grid_points.shape)
        perturbed_points = grid_points + perturbation
        
        return perturbed_points
    
    def _create_nodes_from_points(self, points: np.ndarray):
        """
        Create RoadNode objects from point cloud.
        
        Also merges nearby points (within MIN_INTERSECTION_DISTANCE)
        to prevent duplicate intersections.
        
        Algorithm:
          1. For each point p:
               - If ∃ node n with ||n.position - p|| < MIN_DIST:
                   Skip (merge with existing)
               - Else:
                   Create new node
        
        Args:
            points: [N, 2] array of point positions
        """
        for point in points:
            # Check if nearby node exists
            node_id = self._find_or_create_node(point)
    
    def _find_or_create_node(self, position: np.ndarray) -> int:
        """
        Find existing node near position, or create new one.
        
        Query: Is ∃ node n ∈ nodes with ||n.position - position|| < MIN_DIST?
        
        Using: Linear search (O(N)) for simplicity. Could use KDTree for O(log N).
        
        Args:
            position: [x, y] point
        
        Returns:
            node_id: ID of found or created node
        """
        # Search for nearby nodes
        for node_id, node in self._nodes.items():
            distance = np.linalg.norm(node.position - position)
            if distance < MIN_INTERSECTION_DISTANCE_METERS:
                return node_id  # Found existing node
        
        # Create new node
        node_id = self._node_counter
        self._nodes[node_id] = RoadNode(
            node_id=node_id,
            position=position.astype(np.float32),
            node_type=IntersectionType.ISOLATED  # Will be updated
        )
        self._node_counter += 1
        
        return node_id
    
    def _connect_nodes(self, bounds: Tuple[float, float, float, float]):
        """
        Connect nodes with edges using Delaunay triangulation.
        
        Algorithm:
          1. Compute Delaunay triangulation of node positions
          2. For each edge in triangles:
               - If length < MAX_ROAD_LENGTH:
                   Create bidirectional edges
          3. Remove crossing edges (planarity)
        
        Mathematical basis:
          - Delaunay triangulation maximizes minimum angle
          - Natural connectivity pattern for urban streets
        
        Args:
            bounds: (x_min, y_min, x_max, y_max)
        """
        from scipy.spatial import Delaunay
        
        if len(self._nodes) < 3:
            return  # Can't triangulate fewer than 3 points
        
        # Extract node positions
        node_ids = sorted(self._nodes.keys())
        positions = np.array([
            self._nodes[nid].position for nid in node_ids
        ])
        
        # Compute Delaunay triangulation
        try:
            tri = Delaunay(positions)
        except Exception as e:
            raise ValueError(f"Delaunay triangulation failed: {e}")
        
        # Extract edges from triangles
        edges_set = set()
        for triangle in tri.simplices:
            for i in range(3):
                p1, p2 = triangle[i], triangle[(i+1) % 3]
                # Normalize edge (smaller node ID first)
                edge = tuple(sorted([p1, p2]))
                edges_set.add(edge)
        
        # Create road edges from Delaunay edges
        for idx1, idx2 in edges_set:
            node_id1 = node_ids[idx1]
            node_id2 = node_ids[idx2]
            
            # Check length constraint
            pos1 = self._nodes[node_id1].position
            pos2 = self._nodes[node_id2].position
            length = np.linalg.norm(pos2 - pos1)
            
            if length > MAX_ROAD_LENGTH_METERS:
                continue  # Skip too-long edges
            
            # Create bidirectional edges
            self._create_edge_pair(node_id1, node_id2, length)
    
    def _create_edge_pair(self, node_id1: int, node_id2: int, length: float):
        """
        Create bidirectional edge pair (two directed edges).
        
        Args:
            node_id1, node_id2: Node IDs
            length: Euclidean distance
        """
        # Forward edge
        edge_fwd_id = self._edge_counter
        edge_fwd = RoadEdge(
            edge_id=edge_fwd_id,
            start_node_id=node_id1,
            end_node_id=node_id2,
            road_type=RoadType.MAJOR,  # Will be updated
            centerline=np.array([
                self._nodes[node_id1].position,
                self._nodes[node_id2].position
            ]),
            length=length,
            num_lanes=2,  # Will be updated
            speed_limit_kmh=50,  # Will be updated
            width_meters=10.0
        )
        self._edges[edge_fwd_id] = edge_fwd
        self._edge_counter += 1
        
        # Reverse edge
        edge_rev_id = self._edge_counter
        edge_rev = RoadEdge(
            edge_id=edge_rev_id,
            start_node_id=node_id2,
            end_node_id=node_id1,
            road_type=RoadType.MAJOR,
            centerline=np.flip(edge_fwd.centerline, axis=0),
            length=length,
            num_lanes=2,
            speed_limit_kmh=50,
            width_meters=10.0,
            reverse_edge_id=edge_fwd_id
        )
        self._edges[edge_rev_id] = edge_rev
        self._edge_counter += 1
        
        # Update node adjacency
        edge_fwd.reverse_edge_id = edge_rev_id
        self._nodes[node_id1].outgoing_edges.add(edge_fwd_id)
        self._nodes[node_id2].incoming_edges.add(edge_fwd_id)
        self._nodes[node_id2].outgoing_edges.add(edge_rev_id)
        self._nodes[node_id1].incoming_edges.add(edge_rev_id)
    
    def _assign_road_attributes(self):
        """
        Assign road type, lane count, speed limits based on topology.
        
        Heuristic:
          - Node degree (# connected roads):
              - degree 2: MINOR or RESIDENTIAL
              - degree 3: MAJOR (T-junction)
              - degree 4+: MAJOR (intersection)
          - Edge length:
              - length < 100m: RESIDENTIAL
              - length 100-300m: MINOR
              - length > 300m: MAJOR
        
        Lane count:
          - HIGHWAY: 3-6 lanes
          - MAJOR: 2-4 lanes
          - MINOR: 2 lanes
          - RESIDENTIAL: 2 lanes
        """
        # Compute node degrees
        node_degrees = {
            nid: len(node.incoming_edges) + len(node.outgoing_edges)
            for nid, node in self._nodes.items()
        }
        
        # Update node types
        for nid, degree in node_degrees.items():
            if degree == 0:
                self._nodes[nid].node_type = IntersectionType.ISOLATED
            elif degree == 2:
                self._nodes[nid].node_type = IntersectionType.ISOLATED
            elif degree == 3:
                self._nodes[nid].node_type = IntersectionType.T_JUNCTION
            elif degree >= 4:
                self._nodes[nid].node_type = IntersectionType.FOUR_WAY
        
        # Assign road attributes to edges
        for edge_id, edge in self._edges.items():
            # Determine road type from length + node degree
            start_degree = len(self._nodes[edge.start_node_id].incoming_edges) + \
                          len(self._nodes[edge.start_node_id].outgoing_edges)
            
            if edge.length < 100:
                edge.road_type = RoadType.RESIDENTIAL
                edge.num_lanes = 2
                edge.speed_limit_kmh = 30
            elif edge.length < 300:
                if start_degree >= 3:
                    edge.road_type = RoadType.MAJOR
                    edge.num_lanes = self.rng.choice([2, 3, 4])
                    edge.speed_limit_kmh = 50
                else:
                    edge.road_type = RoadType.MINOR
                    edge.num_lanes = 2
                    edge.speed_limit_kmh = 40
            else:
                edge.road_type = RoadType.MAJOR
                edge.num_lanes = self.rng.choice([3, 4])
                edge.speed_limit_kmh = 60
    
    def _validate_network(self):
        """
        Validate network properties.
        
        Checks:
          1. Connectivity: Graph is connected (all nodes reachable)
          2. Planarity: No crossing edges (Delaunay guarantees this)
          3. Consistency: All edges have valid node references
          4. Topology: No isolated nodes
        
        Raises:
            ValueError: If validation fails
        """
        # Check 1: Connectivity (BFS from first node)
        if not self._nodes:
            raise ValueError("No nodes in road network")
        
        start_node = next(iter(self._nodes.keys()))
        reachable = self._bfs_reachable(start_node)
        
        if len(reachable) < len(self._nodes):
            unreachable = set(self._nodes.keys()) - reachable
            raise ValueError(f"Network not connected. Unreachable nodes: {unreachable}")
        
        # Check 2: Consistency
        for edge_id, edge in self._edges.items():
            if edge.start_node_id not in self._nodes:
                raise ValueError(f"Edge {edge_id}: start node {edge.start_node_id} not found")
            if edge.end_node_id not in self._nodes:
                raise ValueError(f"Edge {edge_id}: end node {edge.end_node_id} not found")
            if edge.length <= 0:
                raise ValueError(f"Edge {edge_id}: invalid length {edge.length}")
        
        # Check 3: No isolated nodes (except allowed)
        for node_id, node in self._nodes.items():
            degree = len(node.incoming_edges) + len(node.outgoing_edges)
            if degree == 0:
                raise ValueError(f"Node {node_id}: isolated node")
    
    def _bfs_reachable(self, start_node_id: int) -> Set[int]:
        """
        BFS to find all reachable nodes from start.
        
        Returns: Set of reachable node IDs
        """
        from collections import deque
        
        visited = {start_node_id}
        queue = deque([start_node_id])
        
        while queue:
            node_id = queue.popleft()
            node = self._nodes[node_id]
            
            for edge_id in node.outgoing_edges:
                next_node_id = self._edges[edge_id].end_node_id
                if next_node_id not in visited:
                    visited.add(next_node_id)
                    queue.append(next_node_id)
        
        return visited
```

# SECTION 5: Mathematical Formulas & Algorithms

## 5.1 Lane Boundary Computation

Given a road centerline C(t) parameterized as:
```
C(t) = P(t), t ∈ [0, 1]
```

For a road with width W and N lanes:
```
Lane_i left boundary:   L_i(t) = C(t) + (w_i + lane_width/2) * N(t)
Lane_i right boundary:  R_i(t) = C(t) + (w_i - lane_width/2) * N(t)

where:
  w_i = (i - N/2) * lane_width    // Lateral position
  N(t) = perpendicular unit vector to C'(t)
  lane_width = W / N
```

## 5.2 Building Placement via Circle Packing

Place N buildings in a polygon P without overlaps:
```
Algorithm:
  1. Initialize: placed_buildings = {}
  2. For each candidate position p ∈ sample(P, M):
       3. Compute circle c with radius r = building_size/2
       4. Check: ∀ b ∈ placed_buildings, distance(c, b) > r_b + r
       5. If valid: placed_buildings ← placed_buildings ∪ {c}
  6. Return placed_buildings
```

## 5.3 3D Bounding Box to 2D Projection

Camera projection matrix K (3x4):
```
K = [f_x  0   c_x  0
      0  f_y  c_y  0
      0   0    1   0]

For 3D point X = [x, y, z, 1]^T:
  x_2d = K @ X
  x_2d_normalized = x_2d[0:2] / x_2d[2]
```

## 5.4 Occlusion Computation via Depth Testing

For each pixel (u, v):
```
depth_rendered(u, v) = z-coordinate of closest rendered object
object_depth(u, v) = z-coordinate from 3D annotation

visibility(object) = (count(depth_rendered < object_depth) / total_pixels) * 100%
```
